# RefBoard

Planche de références visuelles (images, GIF, vidéos) pour l'animation : canevas infini, rangement automatique en lignes justifiées, stockage sur Google Drive.

- En ligne : https://arkogelul.github.io/refboard/
- Brancher Google Drive : [GUIDE-GOOGLE.md](GUIDE-GOOGLE.md)
- Aucune compilation : HTML, CSS et JavaScript simples.
- Publier : **`build.bat`** (push de `main`, GitHub Pages republie le site). En local : **`lancer.bat`**.
- Extension « Vers RefBoard » : `extension\` (voir `extension\INSTALLER.md`), version dans `extension\manifest.json`.
